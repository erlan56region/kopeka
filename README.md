# Копейкино — маркетплейс (объявления · чат · сделки)

Рабочая доска объявлений в духе Авито: люди публикуют товары с фотографиями, находят нужное,
переписываются в чате и договариваются о **личной встрече**, **доставке** или **перевозке**.

Всё написано без внешних зависимостей: Node.js на сервере, чистый JS на клиенте.
Достаточно `npm start`.

```bash
git clone https://github.com/erlan56region/kopeka.git
cd kopeka
npm start          # → http://localhost:8000
```

## Две версии: в интернете и с общим сервером

| Где | Что работает |
| --- | --- |
| <https://erlan56region.github.io/kopeka/> | **Статическая версия** — весь маркетплейс прямо в браузере: каталог, поиск, публикация объявлений с фото, чат, сделки, избранное, профили. Данные лежат в `localStorage` вашего браузера (у каждого свои), кнопка «Сбросить демо» возвращает исходное состояние. |
| `npm start` → <http://localhost:8000> | **Серверная версия** — общая база: объявления и сообщения видны всем пользователям, переписка приходит мгновенно (SSE), фото хранятся на сервере. |

Статику собирает `python3 build_pages.py` (или `npm run build:pages`). Скрипт берёт те же `server/seed.js`,
`public/css/app.css` и `public/js/*.js`, поэтому обе версии выглядят и ведут себя одинаково, и кладёт
результат в корень: `index.html`, `seed/*.jpg` и `404.html` — именно это отдаёт Pages.

> Pages в этом репозитории настроен как **Deploy from a branch → main /**, поэтому после правок в
> `public/` нужно пересобрать и закоммитить корневой `index.html` (workflow `pages.yml` дополнительно
> собирает артефакт в `pages/`). Открывать сайт лучше с главной: прямые ссылки вида `/ad/<id>`
> работают через `404.html`.

## Что умеет

**Объявления.** До 8 фото (сжимаются в браузере до 1280 px и уходят на сервер), категория,
состояние, город и метро, цена, описание. Публикация, редактирование, снятие с публикации.
Счётчик просмотров, похожие объявления.

**Поиск и фильтры.** Полнотекстовый поиск, категории, город, диапазон цен, фильтр по способу
сделки, сортировка (новые / дешевле / дороже / популярные), подгрузка «показать ещё».

**Чат.** Диалог привязан к объявлению, история, время сообщений, счётчик непрочитанных.
Новые сообщения и сделки приходят мгновенно через SSE — без перезагрузки страницы.

**Сделки.** В чате кнопка «Договориться» → тип (встреча / доставка / перевозка), место, дата и
время, цена, комментарий. Предложение появляется в чате карточкой и в разделе «Сделки»,
вторая сторона **подтверждает** или **отклоняет**; затем сделку можно завершить (объявление
автоматически помечается проданным) или отменить.

**Избранное, профили, отзывы.** Список избранного, страница продавца с его объявлениями,
отзывы и рейтинг (★) после сделки.

**Аккаунты.** Регистрация по телефону, пароли — PBKDF2-SHA256, 120 000 итераций, сессии в
HttpOnly-cookie. Светлая/тёмная тема, адаптивная вёрстка (телефон/планшет/десктоп).

## Структура

```
server/
  index.js     HTTP-сервер: статика, JSON API, SSE-события
  store.js     пользователи, сессии, объявления, чаты, сделки, сохранение фото
  seed.js      демо-данные (npm start -- --force-seed — пересеять)
  db.js        JSON-хранилище с отложенной записью
public/
  index.html   оболочка SPA
  css/app.css  стили (зелёная тема «Копейкино», тёмный режим)
  js/api.js    клиент API
  js/ui.js     форматирование, тосты, модальные окна, сжатие фото
  js/views.js  шаблоны страниц
  js/app.js    роутер и вся интерактивность
  seed/        демо-фотографии
data/          db.json + uploads/ (создаётся автоматически, в git не попадает)
build_pages.py    сборка статической версии для GitHub Pages (pages/)
pages/            результат сборки (в git не попадает)
```

## API (кратко)

| Метод | Назначение |
| --- | --- |
| `GET /api/ads?q=&category=&city=&min=&max=&deal=&sort=&limit=&offset=` | поиск объявлений |
| `POST /api/ads` · `PATCH /api/ads/:id` · `DELETE /api/ads/:id` | управление объявлением |
| `POST /api/ads/:id/favorite` · `GET /api/favorites` | избранное |
| `POST /api/chats` `{adId}` | открыть диалог по объявлению |
| `GET/POST /api/chats/:id/messages` | история / отправка сообщений |
| `POST /api/chats/:id/deals` `{type,place,when,price,comment}` | предложить сделку |
| `GET /api/deals` · `POST /api/deals/:id/status` | список и смена статуса сделки |
| `GET /api/events` | SSE: новые сообщения и сделки |
| `POST /api/auth/register` · `/login` · `/logout` | аккаунты |
| `GET/PATCH /api/me` · `GET /api/users/:id` | профиль |
| `POST /api/reviews` | отзыв о продавце |
