Рабочий маркетплейс в духе Авито: объявления с фотографиями, поиск и фильтры, избранное, переписка в реальном времени и сделки — личная встреча, доставка или перевозка.

Эта страница на GitHub Pages — статический хостинг: здесь не работают серверные функции. Сам маркетплейс — Node.js-приложение: npm start → http://localhost:8000.

Что умеет

Объявления

До 8 фото на объявление (сжатие в браузере), категории, состояние, город и метро, цена, описание. Публикация, редактирование и снятие с продажи.

Поиск и фильтры

Поиск по тексту, категория, город, диапазон цен, сортировка по цене/новизне/просмотрам, фильтр по способу сделки.

Чат с продавцом

Диалоги привязаны к объявлению, новые сообщения приходят мгновенно (SSE), есть счётчик непрочитанных.

Сделки

В чате одной кнопкой предлагается личная встреча, доставка или перевозка: место, время, цена, комментарий. Вторая сторона подтверждает или отклоняет, затем сделка завершается.

Избранное и профили

Сохранение объявлений, страницы продавцов, отзывы и рейтинг после сделки.

Аккаунты

Регистрация по телефону, пароли — PBKDF2-SHA256 (120 000 итераций), сессии в HttpOnly-cookie.

Быстрый запуск

git clone https://github.com/erlan56region/kopeka.git
cd kopeka
npm start            # http://localhost:8000
# внешних зависимостей нет, нужен только Node.js 18+

# демо-аккаунт:
#   телефон: +7 999 000-00-01
#   пароль:  demo1234

# пересеять демо-данные:
npm start -- --force-seed

Как устроено

СлойТехнологии
СерверNode.js, модуль http, JSON REST API, SSE для событий чата
ХранилищеJSON-файл data/db.json + загруженные фото в data/uploads/
КлиентЧистый JavaScript (без фреймворков), SPA-роутер на History API, адаптивная вёрстка

Ограничения демо

  • Данные локальные: диск сервера, без внешней БД — для настоящего продакшена нужны PostgreSQL/Redis и файловое хранилище (S3).
  • Нет платежей, SMS-подтверждения телефона и модерации — их можно добавить отдельным этапом.
  • GitHub Pages умеет только статику, поэтому на нём размещена эта страница, а не сам маркетплейс.
